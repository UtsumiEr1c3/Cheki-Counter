## Why

当前偶活总览通过关联记录临时判断活动是否为电切，删除最后一条电切记录后活动会错误地出现在现场活动列表；同时现有页面缺少“全部切奇费用（含电切）+ 现场活动门票”的完整支出口径。活动填写错误时也只能留下错误数据，缺少编辑入口。

## What Changes

- 为活动增加稳定 ID 和“现场参加 / 仅电切”参与方式，活动分类不再依赖当前是否仍有关联记录。
- 修正选择已有活动时的关联逻辑，优先使用活动 ID，避免电切场地生成重复活动。
- 将偶活总览扩展为“活动 / 支出”两个页签：活动列表可按现场、电切或全部筛选；支出页展示全部切奇费用、现场切费用、电切费用、现场门票、参加场数和累计支出，并支持年份筛选。
- 在活动详情页增加编辑入口，支持修改活动名、日期、场地、门票和参与方式；同步修正仍沿用活动旧日期或旧场地的关联记录。
- CSV 导出增加活动稳定 ID 和参与方式；导入继续兼容所有既有列格式，并在新版格式中优先按稳定 ID 复用活动。
- 数据库升级时推断既有活动参与方式：有关联现场记录或无记录的活动视为现场参加，仅有关联电切记录的活动视为仅电切。
- 不增加删除活动功能。

## Capabilities

### New Capabilities

- `event-spending`: 定义全部切奇、现场切、电切、现场门票、参加场数和累计支出的统计口径及展示。

### Modified Capabilities

- `events`: 增加活动稳定 ID、参与方式、列表筛选、按 ID 关联和活动编辑行为。
- `records`: 调整活动选择和记录写入时的参与方式联动。
- `csv-io`: 扩展新版 CSV 的活动字段并保持旧 CSV 导入兼容。

## Impact

涉及 SQLite schema 和迁移、活动与记录模型和 Repository、活动列表与详情页、添加记录和新建活动弹窗、CSV 导入导出以及相关测试。无需新增第三方依赖。
